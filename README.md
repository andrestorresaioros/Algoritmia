# Algoritmia

![Python](https://img.shields.io/badge/Python_3-3776AB?style=flat&logo=python&logoColor=white)

Ejercicios de algoritmia en Python sobre tres familias de problemas clásicos: la sucesión de Fibonacci, el triángulo de Pascal y los números primos. Cada script es independiente y solicita sus datos por consola.

## Contenido

### Fibonacci

| Script | Descripción |
|---|---|
| `Fibonacci/fibo1.py` | Genera los primeros *n* términos de la sucesión e indica cuáles son primos. |
| `Fibonacci/fibo2.py` | Sucesión tipo Fibonacci a partir de dos valores iniciales *A* y *B*, marcando los términos primos. |

### Triángulo de Pascal

| Script | Descripción |
|---|---|
| `Pascal/pascal1.py` | Imprime el triángulo de Pascal con *n* filas usando coeficientes binomiales. |
| `Pascal/pascal2.py` | Patrón de divisibilidad: muestra `1` donde el coeficiente es divisible por *d* y `0` en caso contrario. |
| `Pascal/pascal3.py` | Cuenta las rutas entre dos puntos *A* y *B* de una cuadrícula y la dibuja con Tkinter. |

### Números primos

| Script | Descripción |
|---|---|
| `Primos/primos.py` | Lista los números primos hasta *n* por divisiones sucesivas. |
| `Primos/primos2.py` | Encuentra los pares de primos gemelos (diferencia 2) hasta *n*. |
| `Primos/primos3.py` | Criba de Eratóstenes y pares de primos con diferencia 6 (primos *sexy*). |
| `Primos/primos4.py` | Criba de Eratóstenes y pares de primos con diferencia *2k*, con *k* definido por el usuario. |

## Ejecución

Requiere Python 3 (Tkinter solo para `pascal3.py`). Desde la raíz del repositorio:

```bash
python Primos/primos3.py
```
