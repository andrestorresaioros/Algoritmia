# Algoritmia

Ejercicios de algoritmia resueltos en Python, cada uno en su propia carpeta.

## Contenido

- Fibonacci/ — generación de la serie de Fibonacci
- Pascal/ — construcción del triángulo de Pascal
- Primos/ — identificación y generación de números primos

## Objetivo

Practicar el diseño de algoritmos y el uso de estructuras de control, recursión e iteración sobre problemas clásicos.

## Ejecución

Requiere Python 3. Desde la raíz del repositorio:

    python Fibonacci/<archivo>.py

Sustituir la carpeta y el archivo según el ejercicio que se quiera ejecutar.
